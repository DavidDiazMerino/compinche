## Modelos de Meta en el vídeo

| Modelo | Qué hace | Dónde |
|---|---|---|
| Muse Spark 1.3 | Observar y preguntar, comprobar si una respuesta explica algo, guiar al aprendiz, comparar gestos | Meta Model API |
| Muse Voice Transcribe 1.0 | Escucha continua | Meta Model API (WebSocket) |
| SAM 3.1 | Recipiente, referencia de escala y herramienta destacada | Meta Model API |
| Muse Glimmer 30B | Convertir cada explicación en ficha (título, categoría, resumen) en segundo plano; opcionalmente, responder al aprendiz | GPU local (vLLM, FP8), con Spark de respaldo |
| MapAnything (Apache-2.0) | Geometría métrica para medir | GPU local |
| CoTracker3 | Seguimiento de puntos para alinear gestos | GPU local |

## Volver a grabar una toma

```sh
npm run demo                       # http://127.0.0.1:8017/#teach · botón «Vista de gafas» para grabar
backend/glimmer/serve.sh           # opcional: Muse Glimmer en :8100; luego COMPINCHE_GLIMMER_URL=http://127.0.0.1:8100/v1
```

Medición y gestos necesitan `COMPINCHE_MEASURE_IMAGE`, `COMPINCHE_SAM_CACHE` y `COMPINCHE_TORCH_CACHE` (ver [MEASURE.md](../backend/MEASURE.md)).

**Con el móvil por cable:** `adb reverse tcp:8017 tcp:8017` y abrir `http://localhost:8017/#teach` en Chrome del móvil. Al ser `localhost`, Chrome permite cámara y micrófono.

**Con el móvil en otra casa:** la cámara del navegador necesita HTTPS. Con Tailscale, sin abrir nada a internet:

```sh
COMPINCHE_ALLOWED_HOSTS=<tu-equipo>.ts.net npm run demo
tailscale serve --bg --https=443 http://127.0.0.1:8017    # solo visible dentro de tu tailnet
tailscale serve --https=443 off                           # al terminar
```

La app no tiene cuentas: mientras `serve` esté activo, cualquier equipo de la tailnet puede abrirla.

## Muse Glimmer en la GB10: medidas reales (2 nov)

En FP8 con vLLM (`backend/glimmer/serve.sh`): 32 GB de pesos, unos 8 min de arranque y **unos 7,5 tokens/s**, porque en un modelo denso de 30B manda el ancho de banda de memoria. Con `reasoning_strength: minimal` responde bien a «¿La leche era fría?» citando la ficha y a «¿Cuánta sal?» con «Eso no lo explicó», pero tarda **unos 35 s**.

Por eso Glimmer elabora las fichas en segundo plano (unos 65 s, sin bloquear nada) y Spark responde en directo. Si se termina la sesión antes, las fichas pendientes se siguen elaborando y la pantalla lo indica. `COMPINCHE_GLIMMER_GUIDE=1` le da también las respuestas al aprendiz, con 12 s de margen antes de pasar a Spark.
